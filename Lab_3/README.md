`ascii.asm` и `expression.asm` самостоятельные: нужные процедуры находятся
внутри каждого файла, дополнительные include-файлы не требуются.

В терминале VS Code проекта:

```bash
lab3
run ascii A
run expression 5 2 6
run expression.c 5 2 6
```

Ожидаемые результаты: `65`, `6`, `6`.

В Colab выбрать среду Python 3 / CPU, подключиться и выполнить ячейки сверху вниз.
Установка FASM и остальных инструментов включена. Исходники находятся в ноутбуке;
никакие дополнительные файлы из репозитория для выполнения отчёта не нужны.

Новый отчёт содержит пояснения к каждому заданию, сравнение ASM и C,
100 дополнительных воспроизводимых наборов, проверки границ int64,
ошибочного ввода, деления на ноль и переполнения. Встроены три изображения
фактического вывода программ. Сохранённые результаты получены выполнением
в Ubuntu через WSL 2; в Colab проверки можно воспроизвести заново.
